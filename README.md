# 핏로그 — 웨이트·러닝 운동기록 앱

달력으로 관리하는 **웨이트 + 러닝** 운동기록 웹앱(PWA)입니다.
설치나 서버 없이 폰 홈 화면에 추가하면 앱처럼 동작하고, 오프라인에서도 쓸 수 있습니다.

## 주요 기능

| 구분 | 기능 |
|---|---|
| 📅 달력 | 월간 달력에 날짜별 기록 표시 (🟠 웨이트 / 🟢 러닝), 날짜를 눌러 기록 추가·조회 |
| | 주간 목표 진행률, 🔥 연속 운동일, 월간 요약 (운동일·볼륨·거리) |
| 🏋️ 웨이트 | 세트별 **무게(kg)·횟수** 기록, 세트 완료 체크 |
| | **이전 기록** 표시 (탭하면 그대로 채움), 워밍업 세트 구분 (세트 번호 탭) |
| | **휴식 타이머** 자동 시작 (운동별 휴식 시간 설정, 진동·알림음) |
| | **신기록(PR)** 자동 감지 🏆 (추정 1RM, Epley 공식) |
| | 운동 시간 자동 측정, 볼륨·칼로리 자동 계산 |
| | 운동 라이브러리 45종 + 나만의 운동 추가 |
| 🏃 러닝 | **거리(km)·시간·페이스·칼로리** 기록 (페이스/칼로리 자동 계산, 칼로리는 직접 수정 가능) |
| | **GPS 측정 모드**: 실시간 거리·시간·페이스, 1km 구간 기록 + 진동 알림, 경로 그림 |
| | 직접 입력 모드: 워치·트레드밀 기록 옮겨 적기 |
| 📋 루틴 | **추천 루틴**: 초보자 전신 A/B, 5x5 스트렝스, PPL 3분할, 상/하체 2분할, 러너 보강운동 |
| | **추천 러닝**: 걷기-달리기 인터벌(런린이), 이지런, 템포런, 인터벌, LSD |
| | **내 루틴** 만들기·편집, 추천 루틴 복사 후 수정, 오늘 운동을 루틴으로 저장 |
| | 루틴 시작 시 지난 무게를 미리 채워 줌 (점진적 과부하) |
| 📈 통계 | 웨이트: 주간 볼륨 그래프, 부위별 세트 비율, 운동별 1RM 추이·최고 기록 |
| | 러닝: 주간 거리 그래프, 페이스 추이, 1/5/10km·하프 이상 최고 페이스 |
| | 체중: 기록 + 변화 그래프 (최신 체중이 칼로리 계산에 자동 반영) |
| ⚙️ 설정 | 체중, 기본 휴식 시간, 주간 목표, 주 시작 요일, 다크 모드 |
| | 백업 내보내기/불러오기(JSON), 엑셀용 CSV 내보내기 |

### 참고한 인기 앱 기능
- **Strong / Hevy** (웨이트): 이전 기록 표시, 세트 완료 시 휴식 타이머, PR 감지, 루틴 템플릿, 워밍업 세트
- **Nike Run Club / Strava / 런데이** (러닝): GPS 실시간 측정, km 구간 기록, 단계별 러닝 플랜(걷기-달리기)
- **플랜핏 / 오늘의 운동** (국내): 달력 중심 기록, 추천 루틴, 주간 목표

### 계산식
- 러닝 칼로리 ≈ `1.036 × 체중(kg) × 거리(km)` (추정치)
- 웨이트 칼로리 ≈ `MET 5.0 × 체중(kg) × 운동시간(h)` (추정치)
- 추정 1RM = `무게 × (1 + 횟수 / 30)` (Epley)

## 실행 방법

빌드 과정이 없는 순수 HTML/CSS/JS입니다.

```bash
# 1) 로컬에서 실행
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

### 폰에서 앱처럼 쓰기 (추천)
GPS와 오프라인 기능은 **https** 주소에서만 동작합니다. GitHub Pages로 무료 배포하면 됩니다.

1. GitHub 저장소 → **Settings → Pages**
2. Source: `Deploy from a branch`, Branch: 이 브랜치(또는 main) / `/ (root)` 선택 후 저장
3. 1~2분 뒤 나오는 `https://<아이디>.github.io/<저장소>/` 주소를 폰에서 열기
4. 홈 화면에 추가
   - **아이폰(Safari)**: 공유 버튼 → `홈 화면에 추가`
   - **안드로이드(Chrome)**: 메뉴 ⋮ → `홈 화면에 추가` / `앱 설치`

## 데이터 저장
- 모든 기록은 **해당 기기의 브라우저(localStorage)** 에 저장되며 외부 서버로 전송되지 않습니다.
- 브라우저 데이터를 지우거나 폰을 바꾸면 기록이 사라질 수 있으니 **설정 → 백업 내보내기**를 주기적으로 해 주세요.

## 알려진 제한
- GPS 측정은 브라우저 특성상 **화면이 꺼지거나 다른 앱으로 전환하면 측정이 멈출 수 있습니다.** (화면 켜짐 유지를 요청하지만 기기에 따라 다름) 장거리는 워치 기록을 직접 입력하는 것을 권장합니다.
- 기기 간 자동 동기화, 애플 건강/구글 헬스 커넥트 연동은 네이티브 앱이 필요해 포함하지 않았습니다.

```
sw.js                 오프라인 캐시
manifest.webmanifest  홈 화면 앱 설정

```
